STREAMSEASON — iPhone PWA

WHAT IT IS
A simple seasonal streaming hub. It does not store streaming passwords.
Each service button opens the service's official website so you can sign in there.

FILES
- index.html
- style.css
- app.js
- manifest.json
- sw.js
- icon.svg

DEPLOYMENT
Upload all files to the same folder on any static host such as GitHub Pages, Netlify, or Cloudflare Pages.

IPHONE INSTALL
1. Open the deployed site in Safari.
2. Tap Share.
3. Tap "Add to Home Screen".
4. Tap Add.

SEASONS
The app automatically uses:
Winter: Dec-Feb
Spring: Mar-May
Summer: Jun-Aug
Fall: Sep-Nov

Tap the season button to preview another season. The selected preview is remembered on that device.
